Contas de afiliados

Como achar minha API pelo celular?

Passo a passo para afiliados Shopee que usam Android:

  1. Abra o Chrome no celular (não o aplicativo Shopee).
  2. Acesse affiliate.shopee.com.br/open_api e entre na sua conta de afiliado.
  3. No Chrome, toque nos três pontos (⋮) e marque Site para computador, caso o menu da Shopee não apareça.
  4. Na página, procure Abrir API ou Open API no menu. Se houver o cartão Meu API, copie App ID e Senha/Secret da API. Não é sua senha de login.
Não encontrou “Abrir API”? Talvez sua conta ainda não tenha acesso. Procure no suporte da Shopee a solicitação “Quero ativar a API”. O acesso depende de análise da plataforma.
O link abriu o app Shopee? Volte ao Chrome, digite o endereço na barra e tente abrir o site na versão para computador. Alguns celulares encaminham o login para o aplicativo.

Enquanto isso: use seus próprios links de afiliado em Produtos. O Sellutions ainda não recebe App ID/Secret com segurança: não cole esses códigos no app nem os envie por mensagem.

TikTok Shop: não há API para você procurar no celular. O Sellutions precisa obter aprovação de integração no TikTok Shop Partner Center antes de oferecer login de criador.
